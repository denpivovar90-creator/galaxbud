# Запуск сайту з адмінкою

Інструкція для новачка. Робиться один раз, займе 15–20 хвилин.

---

## Що змінилося

Раніше сайт був набором готових HTML-файлів. Тепер він **збирається автоматично**
з текстів, які лежать окремо. Завдяки цьому з'явилася адмінка: ви заходите
за адресою `ваш-сайт/admin`, правите текст у звичайних полях, натискаєте
«Зберегти» — і сайт сам оновлюється.

Зовні для відвідувача нічого не змінилося.

---

## Крок 1. Замінити вміст репозиторію

**Важливо:** старі файли треба прибрати, інакше вони конфліктуватимуть з новими.

1. Відкрийте свій репозиторій на GitHub.
2. Видаліть звідти **всі** старі файли: `index.html`, `en.html`, `styles.css`,
   `script.js`, усі картинки, `netlify.toml`.
   (Відкриваєте файл → кнопка з кошиком угорі справа → Commit changes.)
3. Завантажте нові файли з архіву, **зберігаючи структуру папок**:

```
package.json
.eleventy.js
netlify.toml
src/
  index.njk
  en.njk
  sitemap.njk
  robots.njk
  styles.css
  script.js
  _includes/page.njk
  _data/*.json
  admin/index.html
  admin/config.yml
  img/*.png, *.jpg, favicon.ico
```

Найпростіше: розпакуйте архів у себе на комп'ютері, потім на GitHub натисніть
**Add file → Upload files** і перетягніть туди відразу всі папки.

---

## Крок 2. Перевірити збірку на Netlify

Netlify тепер має не просто копіювати файли, а збирати сайт.
Файл `netlify.toml` це вже налаштовує, тому зазвичай нічого робити не треба.

Перевірте: панель Netlify → **Site configuration → Build & deploy**:
- Build command: `npm run build`
- Publish directory: `_site`

Після завантаження файлів Netlify збере сайт сам (30–60 секунд, перший раз довше).
Якщо статус деплою **Published** — усе працює.

---

## Крок 3. Увімкнути вхід в адмінку

Це потрібно, щоб у адмінку могли заходити тільки ви.

1. Панель Netlify → ваш сайт → **Integrations** (або Settings) → знайдіть **Identity**.
2. Натисніть **Enable Identity**.
3. Там же відкрийте **Services → Git Gateway** і натисніть **Enable Git Gateway**.
   Це дозволяє адмінці зберігати зміни у ваш репозиторій.
4. Відкрийте **Identity → Registration** і поставте **Invite only**.
   Інакше зареєструватися зможе будь-хто.

---

## Крок 4. Створити собі доступ

1. У розділі **Identity** натисніть **Invite users**.
2. Впишіть свою пошту, надішліть запрошення.
3. На пошту прийде лист — відкрийте його **саме на сайті** (посилання веде на ваш сайт)
   і придумайте пароль.
4. Готово. Тепер заходьте на `ваш-сайт.com/admin`

> Якщо лист не приходить — перевірте теку «Спам».
> Якщо після кліку сторінка порожня — допишіть `/admin/` в адресу вручну.

---

## Крок 5. Як користуватися

Зайшовши в адмінку, ви побачите розділи зліва:

| Розділ | Що там правити |
|---|---|
| **Налаштування сайту** | Телефон, пошта, адреса, графік, соцмережі, Telegram |
| **Тексти — українська** | Усі написи на сайті: заголовки, описи, кнопки |
| **Тексти — англійська** | Те саме для англійської версії |
| **Послуги (картки)** | Шість карток у блоці «Що ми робимо» — текст і фото |
| **Переваги** | Блок «Переваги формату All-in-one» |
| **Партнери** | Логотипи партнерів — додати, прибрати, замінити |
| **Портфоліо** | Ваші виконані проєкти |

Змінили щось → **Publish → Publish now** → через хвилину сайт оновився.

---

## Про портфоліо

Зараз список порожній, тому на сайті показується напис
«Ведуться технічні роботи…».

Щойно ви додасте перший проєкт — напис зникне сам, замість нього
з'явиться сітка з вашими об'єктами. Нічого додатково вмикати не треба.

---

## Соцмережі

У «Налаштуваннях сайту» поля Facebook та Instagram зараз порожні,
тому посилання в підвалі не показуються. Впишете адреси — вони з'являться.

---

## Google

Разом з адмінкою зроблено все для індексації:

- `sitemap.xml` та `robots.txt` генеруються самі
- проставлені canonical та hreflang (Google розуміє, що укр і англ версії — одна компанія)
- додана мікророзмітка: назва, адреса, телефон, графік роботи
- Open Graph — при надсиланні посилання в месенджер показується картинка й опис

**Що зробити вам:**

1. У «Налаштуваннях сайту» перевірте поле **Адреса сайту** — там має бути
   справжня адреса (наприклад `https://galaxplus.com.ua`). Від неї залежить
   карта сайту.
2. Зайдіть на [search.google.com/search-console](https://search.google.com/search-console),
   додайте сайт, підтвердьте право власності (простіше через DNS або файл).
3. Там же надішліть карту сайту: `sitemap.xml`

Google зазвичай заходить протягом кількох днів.

> **Важливо про домен.** Якщо сайт досі на безкоштовній адресі `*.netlify.app`,
> у пошуку він майже не підніметься — пошуковики ставляться до таких піддоменів
> як до тимчасових. Свій домен у зоні .com.ua коштує близько 300–500 грн на рік
> і підключається до Netlify за 10 хвилин.

## Якщо щось пішло не так

**Сайт не збирається (деплой failed).** Відкрийте лог деплою в Netlify —
там буде причина. Найчастіше це неповна структура папок при завантаженні.

**Адмінка відкривається, але порожня.** Перевірте, що файл
`src/admin/config.yml` завантажився і лежить саме там.

**Не виходить зберегти зміни.** Швидше за все не увімкнений Git Gateway (крок 3.3).

**Заявки перестали приходити.** У «Налаштуваннях сайту» перевірте токен
Telegram-бота і список Chat ID — вони тепер зберігаються там, а не в коді.

---

## Локальний перегляд (необов'язково)

Якщо колись захочете дивитися зміни у себе на комп'ютері:

```
npm install
npm start
```

Сайт відкриється за адресою `localhost:8080`.
