# Telegram — заявки з сайту

## Статус: підключено ✅

Бот та отримувачі вже прописані у файлі `script.js`:

```js
const TELEGRAM_BOT_TOKEN = '8477554349:AAFj...';
const TELEGRAM_CHAT_IDS  = ['8784431836', '6719768956'];
```

Заявки надсилаються **обом отримувачам одночасно** — і з попапів у блоці
«Що ми робимо», і з форми в розділі «Контакти».

---

## ⚠️ Обов'язковий крок перед перевіркою

**Кожен з двох отримувачів має один раз написати боту.**

1. Знайти бота в Telegram (за його username — подивитись у @BotFather → `/mybots`).
2. Натиснути **Start**.

Без цього Telegram не дозволить боту надіслати повідомлення — це захист від спаму.
Якщо заявки не приходять, у 9 випадках з 10 причина саме тут.

---

## Як перевірити

1. Відкрити сайт, натиснути будь-яку картку в блоці «Що ми робимо».
2. Заповнити ім'я та телефон, натиснути «Надіслати заявку».
3. Протягом кількох секунд обом має прийти:

```
🔔 Нова заявка з сайту GalaxPlus

📌 Послуга: Будівництво та реалізація
👤 Ім'я: Іван Петренко
📞 Телефон: 0671112233
💬 Коментар: Цікавить ціна та строки

🕒 03.08.2026, 14:22
```

---

## Додати ще одного отримувача

1. Новий отримувач пише боту **Start**.
2. Дізнається свій ID через бота **@userinfobot**.
3. У `script.js` додати ID у список через кому:

```js
const TELEGRAM_CHAT_IDS = ['8784431836', '6719768956', 'НОВИЙ_ID'];
```

---

## Якщо заявки не приходять

**Перевірте Start.** Найчастіша причина — див. вище.

**Відкрийте консоль браузера** (клавіша F12 → вкладка Console) і надішліть тестову
заявку. Там буде точна причина, наприклад:
- `chat not found` — невірний ID або отримувач не натиснув Start
- `Unauthorized` — невірний токен (можливо, його відкликали)

**Заявка доходить лише одному.** Значить другий не натиснув Start — сайт це
не ламає, повідомлення просто йде тому, хто доступний.

---

## Про безпеку

Токен бота видно будь-кому, хто відкриє код сайту (це особливість усіх статичних
сайтів — увесь JS публічний). Максимум, що зможе зробити стороння людина —
надсилати спам у ці два чати. Доступу до ваших акаунтів Telegram токен **не дає**.

Якщо колись знадобиться сховати токен — це робиться через Netlify Functions.
Токен зберігається у налаштуваннях Netlify, у коді сайту його немає взагалі.

Якщо токен скомпрометовано — у @BotFather команда `/revoke` створює новий за хвилину
(тоді треба замінити його в `script.js`).
